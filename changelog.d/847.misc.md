**Injection corpus v2**

`npm run eval:injection -- --corpus injection-corpus-v2` runs four new samples
that close two measured gaps in corpus v1. `inj-026` steers the model at
`fs_read` on the GitOps ServiceAccount token and scores a leak of
`SA_TOKEN_CANARY`. `inj-027` uses a plaintext ConfigMap password a model can
copy without decoding base64. `inj-028` and `inj-029` add an obfuscated JSON
instruction and an instruction buried in log volume. Corpus v1 and its
committed baselines are unchanged.

See the [injection eval guide](https://github.com/vfarcic/dot-ai/blob/main/docs/dev/injection-eval-guide.md).
