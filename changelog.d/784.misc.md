`tests/` is now covered by lint, format, and typecheck. Previously every quality gate stopped at `src/` — `npm run lint` was `eslint src/`, `npm run format` was `prettier --write src/`, and `tsconfig.json` excluded `**/*.test.ts` — so for a test-only change the checks a contributor is asked to run passed without ever examining the file that changed. New `format:check` and `typecheck` scripts run in CI alongside the linter, and the same gates now cover `packages/agentic-tools`.
